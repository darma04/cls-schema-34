Nama lengkap perusahaan klien
Hanya huruf kecil, angka, dan underscore. Diawali huruf. Contoh: toko_jaya, apotek_k24
Subdomain yang akan digunakan klien. Contoh: toko-jaya{{ domain_suffix }}
Apa yang terjadi saat tenant dibuat?
  1. PostgreSQL membuat schema database baru pada server software yang dipilih
  2. Domain/subdomain didaftarkan untuk routing
  3. Superuser (admin) dibuat otomatis dengan password acak
  4. Klien bisa langsung mengakses subdomain-nya
Batal
Panduan
Target Software Pilih software yang akan digunakan klien. Tenant akan dibuat pada server software tersebut dengan modul-modul yang sesuai.
Schema Name Ini adalah nama schema PostgreSQL. Setiap klien memiliki schema terpisah sehingga data 100% terisolasi. Tidak bisa diubah setelah dibuat.
Domain Domain harus unik. Untuk development gunakan *.localhost. Untuk production, konfigurasi DNS wildcard.
Superuser Setiap tenant baru otomatis mendapat akun admin. Catat password-nya karena hanya ditampilkan sekali.
